# demowebs-es.github.io

Redesign demos, one folder per business, served at `https://demowebs-es.github.io/<business>/`.

Every page carries `noindex` and `robots.txt` blocks all crawlers, so the demos are reachable only through the link we send.

See the [organization README](https://github.com/demowebs-es) for the rules each demo follows.
